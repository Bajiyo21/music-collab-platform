# TuneCollab User Guide

## Get Started

Select **Sign In** to enter TuneCollab through the secured account flow. After signing in, the **Dashboard** is your workspace for tracks, playlists, collaborations, favorites, activity, and notifications.

## Upload and Protect a Track

Choose **Upload track**, select an accepted audio file, and complete the title, description, genre, tags, visibility, and optional cover-art fields. The upload screen validates media before submission. TuneCollab records a SHA-256 checksum for the received file to detect an exact duplicate and help verify file integrity. A checksum is not a copyright registration or legal ownership certificate.

Use the **TuneAI metadata assistant** if you want editable suggestions for a release description, discovery genre, and tags. Review and apply only the fields you want; the assistant never changes the upload automatically.

## Discover and Listen

Visit **Explore** to search public tracks, use genre and sorting controls, and open an artist profile. Track pages provide waveform seeking, keyboard playback shortcuts, volume control, queue navigation, shuffle, repeat, favorites, comments, and share actions.

## Collaborate Safely

Open **Collaborate** to join or create a project. In a room, add one of your uploaded tracks as a layer, then use the layer controls and room chat to coordinate. Only the project owner can remove contributors or delete a collaboration. A layer can be removed only by its uploader or the project owner; other contributors cannot delete another musician’s music.

Use **Export WAV** to render the available layers in your browser. The browser must be able to read every layer file for export to succeed.

## Playlists, Feedback, and Notifications

Create playlists from your library, add or remove your tracks, set visibility, share a playlist, and like public collections. Track and collaboration comments remain attached to their relevant music or room. The notification inbox and dashboard activity panel surface invitations, social activity, and collaboration updates.

## Appearance and Troubleshooting

Use the Sun/Moon control to switch between light and dark modes; the selection is remembered on the device. If a page shows an unexpected error, reload it. For sign-in or upload issues, return to the home page, verify that the session is active, and retry with a supported file.
